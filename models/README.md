# Local detection model

The local smoke-test model is `yolo11n.onnx`, downloaded from the official
Ultralytics assets release:

`https://github.com/ultralytics/assets/releases/download/v8.3.0/yolo11n.onnx`

SHA-256:

`634279B40C07C6391472C51AD45B81EBC48706A9A1FE72DD3396322ACD0C053B`

The binary is intentionally ignored by Git (`*.onnx`). Re-download it when
setting up a clean workstation and verify the checksum before use.
