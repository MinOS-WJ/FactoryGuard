# 界面与交互设计

## 1. 设计目标

- 面向非技术的商户店主和物业安保人员；
- 弱化 AI 营销感，以“值守、设备、区域、险情”为主语言；
- 关键信息和动作在首屏可见；
- 出错时说明原因和下一步，而不是暴露工程异常；
- 业务动作必须有状态、结果和可追溯记录。

## 2. 信息架构

| 导航 | 核心任务 |
| --- | --- |
| 工作台 | 查看安全态势、设备在线率、重点画面、待处理险情和值守摘要 |
| 实时画面 | 按区域、状态、关键词筛选并查看视频 |
| 现场问询 | 查询设备/区域/险情，或自然语言登记险情 |
| 险情中心 | 查看详情、确认、解决、误报、重新打开 |
| 区域与设备 | 创建区域、添加摄像头、扫描 ONVIF、导入国标设备 |
| 系统设置 | 品牌横幅、问询服务、国标服务、本地运行环境与配置文件入口 |

## 3. 视觉规范

- 品牌深色：`#17261F`，用于默认顶部横幅；
- 主强调色：深绿 `#176B5B`，用于主操作、选中导航和在线状态；
- 暖灰页面背景：`#F3F1EC`；侧栏：`#F8F6F1`；卡片：白色、12px 圆角、细边框；
- 警告色使用低饱和琥珀与砖红，不使用荧光色、重阴影或大面积装饰渐变；
- 字体优先 Microsoft YaHei UI，回退到系统中文字体；
- 图标使用统一线性矢量图标，选中导航使用深绿底和白色图标；
- 视觉语言强调“现场值守与运营”，避免通用 AI 产品常见的发光、机器人图标和营销式大标题。

## 4. 关键交互

### 摄像头卡片

- 单击“查看”或双击卡片打开实时画面；
- 在线、离线、待检测使用不同颜色；
- 离线状态给出网络/供电检查提示；
- 状态提示可显示设备健康详情。

### 险情列表

- 选中行高亮；
- 详情显示等级、状态、时间、区域、摄像头、来源和上报人；
- 状态动作立即生效并刷新列表；
- 高危和紧急险情优先展示。

### 现场问询

- 空状态提供“查现场、问险情、报险情”三类引导；
- 输入为空时发送按钮禁用；
- `Ctrl + Enter` 发送；
- 显示回答来源：本地规则或可选文字服务；
- 右侧提供常用问题与配置入口。

### 摄像头接入向导

- ONVIF：只显示地址、账号、密码；
- GB/T 28181：只显示设备编号和通道；
- RTSP：显示地址、码流名称和账号密码；
- 非 RTSP 协议隐藏“测试连接”，避免误导。

### 启动与托盘

- 启动画面显示品牌、阶段、进度和版本，背景保持深色纯色，不使用大面积渐变或多色插画；
- 主窗口关闭后隐藏到托盘；
- 首次隐藏时通知用户程序仍在运行；
- 托盘支持打开控制台、上报险情、刷新状态、退出。

### 用户 SVG 横幅

- 默认横幅横跨应用顶部，始终提供完整品牌识别；
- 客户可在系统设置中选择自己的 SVG，整条替换默认横幅；
- 支持 64～160px 高度，等比铺满并裁切，不拉伸变形；
- 建议宽高比为 8:1 至 12:1；文件上限为 5 MB；
- 无效 SVG、包含脚本或 JavaScript 的 SVG 会被拒绝并恢复默认横幅；
- “恢复默认横幅”不会留下空白区域；
- 文件和相对路径写入 JSON 配置，可手工替换。

## 5. 响应式规则

- 最小窗口：1280×680；
- 窗口高度不足 820 时，工作台重点画面收敛为 2 路；
- 大屏优先展示 4 路重点画面；
- 页面禁止水平滚动，内容超出时只纵向滚动；
- 设置页采用左侧配置、右侧说明的双栏布局。

## 6. 可访问性与文案

- 不只依赖颜色区分状态，同时显示状态文字；
- 密码字段默认隐藏；
- 所有危险操作使用明确动词；
- 空状态提供下一步操作按钮；
- 错误提示包含可理解的失败原因。
