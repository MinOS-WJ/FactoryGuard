# 测试计划

## 1. 测试目标

验证 FactoryGuard 智守在单机 Windows 环境下的配置、设备管理、险情闭环、现场问询、启动画面、后台常驻和线程清理符合验收标准。

## 2. 测试范围

### 包含

- JSON 配置文件读写、默认值合并、错误处理；
- 在线 SQLite 一致性备份、首次运行配置落盘、配置打包、备份状态摘要、安全恢复和版本兼容性；
- 旧注册表/数据库配置迁移；
- 领域模型、区域拓扑、险情状态流转/重新打开、处置审计展示和对话持久化；
- 摄像头暂停/恢复接入、重复连接检测、共享设备订阅生命周期、停用状态、检测时间和启动/周期自动检测定时器；
- 原生事件去重缓存的重复检测和长期运行上限；
- 国标 SIP 服务端口绑定成功、失败反馈和运行状态检测；
- 本地规则问询与险情自然语言登记；
- LLM 配置、启停和离线回退；
- 险情通知 JSON 配置、Webhook 签名、SMTP 邮件、短信网关与测试通知；
- ONVIF、GB/T 28181、RTSP 适配器单元与集成测试；
- 多摄像头 ONVIF、GB/T 28181 和 RTSP 模拟器联调；
- 客户 SVG 横幅、默认横幅回退和非法文件校验；
- ResourceWarning 零泄漏门禁；
- 无视觉模型文件、依赖和命令的产品边界检查；
- Ruff 静态检查、Ruff 格式和 Python 编译门禁；
- 商户控制台构建、页面切换、筛选和状态更新；
- 实时预览线程生命周期与敏感信息隐藏；
- 启动画面渲染；
- 系统托盘后台常驻与单实例运行保护；
- 单路和最多四路实时画面查看、单路/单格断流重连、超过四路时的画面选择、分级预览参数及线程清理；
- 周期刷新只更新当前页面并保留状态栏提示；
- 全量回归测试。

### 不包含或需现场完成

- 真实 ONVIF/GB28181 摄像头型号兼容性；
- 真实 NVR 多通道并发压力；
- Windows 安装包签名和升级回滚；
- 7×24 小时长时间稳定性；
- 多用户、多进程并发访问同一配置或数据库；
- 真实 4 路高清摄像头长时间同时解码压力。

## 3. 测试层级

| 层级 | 说明 | 主要文件 |
| --- | --- | --- |
| 单元测试 | 配置、拓扑、日程、规则与通知工具函数 | `tests/test_*.py` |
| 集成测试 | 设备管理、GB28181、存储、通知、现场问询 | `tests/test_device_integration.py`、`tests/test_incident_notifications.py` 等 |
| 模拟联调 | 多路 ONVIF/GB28181 模拟设备与 RTSP 首帧 | `tests/test_camera_simulator.py` |
| UI 测试 | PySide6 离屏构建、交互、响应式布局和线程 | `tests/test_merchant_console.py`、`tests/test_stream_probe.py` |
| 黑盒验收 | 通过真实 `src/main.py` 检查命令输出 | `tests/test_acceptance_blackbox.py` |
| 视觉检查 | 启动画面和多分辨率页面截图 | 离屏截图检查 |

## 5. 测试数据

- 空数据库：验证首次启动和空状态；
- 商户演示数据：1 个园区、4 个区域、6 台摄像头、3 条险情；
- 临时配置：每个 UI/配置测试使用独立临时 JSON；
- 模拟设备事件：GB/T 28181 区域入侵；
- 虚拟多摄像头：ONVIF、GB/T 28181、RTSP 端点与测试画面；
- 客户 SVG：有效横幅、脚本注入横幅和恢复默认；
- 伪造媒体上下文：验证实时预览退出和凭据隐藏；
- 已移除的视觉模型目录、旧 CLI 命令和旧工程界面回归。

## 6. 准入与退出

### 准入

- 依赖安装完成；
- 配置示例有效；
- 主入口可导入；
- 无未解决的阻断级缺陷。

### 退出

- 全量自动测试通过；
- Ruff 静态检查、Ruff 格式检查和 Python 编译检查通过；
- 需求验收表中阻断项通过；
- 启动画面、托盘和主要页面完成人工检查；
- 已知未验证范围记录在测试报告。

## 7. 风险

| 风险 | 应对 |
| --- | --- |
| 自动测试无法覆盖真实设备 | 增加现场联调清单 |
| 离屏 Qt 与真实 Windows 渲染有差异 | 在目标 Windows 桌面复核截图 |
| 明文配置泄露 | 限制目录权限、禁止提交实际配置文件 |
| 国标端口被占用 | 在部署检查中验证端口和错误提示 |
| ONVIF WS-Discovery 受防火墙/多播影响 | 同时保留 HTTP 直连验证，并在目标局域网复核 UDP 3702 |
| 关闭窗口后后台误解为退出 | 托盘通知、用户手册明确说明 |
