## 5. 重点白盒覆盖项

### 5.1 配置与存储

- JSON 配置默认值合并、嵌套字段递归更新、写失败回滚、并发写入互不覆盖；
- 旧注册表/数据库配置一次迁移，已有模型、服务商、国标设置不被空值覆盖；
- 配置文件非法 JSON 不覆盖原文件；
- 业务数据保留期清理（设备事件、审计、通知出队、**问询记录**）；
- 在线备份、清单一致性校验、恢复前安全备份、失败回滚、版本兼容性。

### 5.2 设备接入

- ONVIF 探测、通道枚举、RTSP 首帧、凭据注入与脱敏；
- GB/T 28181 注册、目录、告警、INVITE 后 RTP 首帧、通道号 `:ss` 规范化；
- 原生事件订阅建立/失效/恢复，共享物理设备的订阅生命周期；
- 事件去重使用唯一指纹，先进先出缓存上限 10000 条。

### 5.3 险情闭环

- 创建、确认、解决、误报、重新打开，非法状态转换不写审计；
- 险情保留事发当时的场所/区域/摄像头快照，改名后仍可追溯；
- **区域别名匹配**："仓库"命中"成品仓库"，去掉方位词命中"东侧大门"；
- **区域歧义不猜测**：两个区域同时匹配时保留未指定，提示补充位置；
- **补充位置**：详情页可为无区域险情指定区域，写快照并记入处置记录；
- 处置说明随状态变更写入审计，并出现在导出清单；
- CSV 导出 UTF-8 BOM，Excel 可直接打开。

### 5.4 现场问询

- 无外部服务时本地规则问答可用；
- 外部服务配置错误不阻断启动，回退本地规则且不回显密钥；
- HTTP 错误响应统一关闭，不泄漏套接字；
- 5 分钟内重复上报同内容同位置不重复建单、不重复通知；
- 回答引用 ID 可在险情中心追溯。

### 5.5 通知投递

- Webhook HMAC-SHA256 签名、SMTP 邮件、短信网关；
- 投递结果持久化、失败渠道单独重试、失败渠道指数退避持续补发；
- 线程异常兜底只标记本次请求的渠道，不污染已成功渠道；
- 已停用渠道不进入手动或自动重试。

### 5.6 界面与线程

- 六个页面在 1120x640 / 1280x720 / 1366x768 / 1440x900 无横向溢出；
- 摄像头卡片显示检测时间、订阅异常提示；
- 筛选时同时显示命中数与总数；
- 预览线程退出时释放解码器，关闭对话框不崩溃；
- 关闭窗口后隐藏到托盘，后台计时器继续运行；
- **中文字体装载**：离屏与精简系统下显式注册微软雅黑，避免中文渲染成方块。

## 6. 本轮修复的问题

| 问题 | 修复 |
| --- | --- |
| 问询上报险情时区域必须完全同名才匹配，"仓库"无法命中"成品仓库" | 引入区域别名、方位词与场所类型匹配；歧义时不猜测 |
| 险情创建后无法补充区域，助手提示商户去补充却无从操作 | 详情页新增"补充位置"，写入快照并记入处置记录 |
| 摄像头告警订阅断开只在状态栏闪过 10 秒，商户事后无从察觉 | 摄像头卡片直接显示"告警订阅异常"及原因 |
| 现场问询聊天记录从不清理，后台常驻会让数据库持续膨胀 | 聊天记录纳入保留期清理 |
| 健康检查把整机 CPU 占用算作失败原因 | 整机负载只警告，并新增"机器负载"提示行 |
| 文字问询与通知收到 HTTP 错误时响应对象未关闭 | 新增 `src/factoryguard/net.py` 统一关闭错误响应 |
| 实时画面与设备页只显示筛选后数量 | 统一"共 N 台 / N / 总数 台"口径 |
| 实时画面筛选栏在 1120x640 下出现横向滚动 | 收窄选择器最小宽度，筛选栏放回一屏 |
| 国标服务刚启动无设备注册时仍显示绿色"运行中" | 状态按"等待注册 / 等待目录 / 待导入 / 已接入"分级 |
| 国标模拟器端到端用例在机器繁忙时因 SIP 握手超时偶发失败 | 放宽跨进程模拟器的等待窗口 |
| 模拟器 RTP 接收缓冲区过小，高清录像丢包导致画面竖条纹 | 缓冲区提升至 8 MB，并新增画面保真度回归用例 |
| 离屏渲染环境无中文字体，界面全部渲染成方块 | 主题层显式注册微软雅黑字体文件 |
| 退出与测试收尾时 FFmpeg 子进程残留，长期运行会累积僵尸编码器 | 启动时创建独立进程组，退出时连同子进程树一并结束；模拟器补上 SIGBREAK 处理 |

## 7. 未验证范围与已知限制

- Windows 托盘、开机自启动、真实桌面窗口交互需在目标机器人工复核；
- 真实 ONVIF / GB28181 摄像头型号兼容性必须现场联调；
- 外部大模型服务的真实网络链路未被自动化覆盖（配置、错误与回退已覆盖）；
- 4～32 路摄像头长时间并发与断网恢复仍需压力测试；
- 安装包、代码签名与升级回滚不在自动化范围。

## 8. 结论

白盒测试 383 项全部通过，分支覆盖率 77%，资源零泄漏，静态与格式门禁全绿。
本轮共修复 13 个真实业务与工程缺陷，其中 3 个直接影响商户日常使用
（区域识别、位置补充、订阅异常可见），2 个影响交付证据可信度与长期运行稳定性
（画面保真度、FFmpeg 进程树残留）。
