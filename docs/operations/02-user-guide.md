# 用户手册

## 1. 第一次使用

1. 打开 FactoryGuard；
2. 进入“区域与设备”；
3. 创建“东门”“仓库”“停车场”等区域；
4. 点击“添加摄像头”；
5. 选择接入方式并保存；
6. 到“实时画面”检查连接状态。

## 2. 添加摄像头

### ONVIF

选择“ONVIF 摄像头”后可扫描局域网设备。发现多台设备时，列表会显示设备名称和 ONVIF 服务地址，选择目标摄像头后系统会自动预填，不需要手工复制地址；也可以直接填写服务地址和设备账号。保存后打开实时画面，平台会获取视频通道。

设备支持 ONVIF 事件服务时，平台会自动建立 PullPoint 告警订阅；订阅成功、异常或断开的原因可在摄像头状态提示中查看。

### GB/T 28181

先在“系统设置”启用国标服务，填写平台编号、SIP 域和端口。设备注册后，点击“导入已注册设备”，选择区域即可。

导入会把本次选中的全部设备与通道一次性写入：任何一路写入失败，整批都不会保存，不会留下半套数据。若同一国标设备编号已归属其他场所或区域，平台会拒绝导入并提示到原区域补充通道。多门店存在同名区域时，区域列表会显示“场所 / 区域”，便于确认归属。

### RTSP

填写 `rtsp://` 地址、码流名称和账号密码。保存后可直接查看画面。

### 重复摄像头保护

如果相同 RTSP 地址、相同 ONVIF 设备通道或相同国标设备通道已经接入，平台会阻止重复保存，并提示已有摄像头名称和所属区域。请直接编辑现有设备，不要重复添加。

### 导出险情清单

在“险情中心”筛选好范围后，点击工具栏右侧的“导出清单”，即可把当前结果保存为 CSV 表格。

导出内容包含：发生时间、险情编号、标题、等级、状态、来源、场所、区域、摄像头、上报人、描述和处置记录。

- 文件使用 UTF-8 BOM 编码，Excel、WPS 直接双击打开不会出现乱码；
- 导出遵循当前筛选条件（区域、等级、状态、关键字），只导出显示出来的记录；
- 区域或摄像头已删除时，导出仍显示事发当时的名称，可直接用于事故报告。

### 编辑或删除摄像头

在“实时画面”或“区域与设备”中点击摄像头卡片上的“管理”：

- “编辑”可修改摄像头名称、所属区域、地址、设备编号、通道和码流信息；
- 设备账号或密码分别留空时，会保留对应的现有值；密码不会因只修改账号而被清空；
- 编辑连接地址时，如果该地址已被另一台摄像头使用，系统会阻止保存以避免重复取流和重复告警；
- 同一场所内不能创建同名区域；不同场所可使用相同区域名称；
- RTSP 账号和密码可以包含 `@`、`:`、`/`、`#`、`%` 等特殊字符，平台会自动进行 URL 编码；
- RTSP 支持 IPv6 主机地址，拆分账号信息后会保留方括号和端口；
- 修改设备地址、账号或密码后，旧健康状态和旧解析码流会自动失效；下次预览会重新获取码流；
- “暂停接入”用于设备维护，暂停后不取流、不生成设备险情，但仍保留配置和历史记录；
- “恢复接入”会重新启用摄像头；共享物理设备的其他启用通道不会受到影响；
- “删除”会移除摄像头和相关码流，但历史险情记录仍保留；
- 同一物理设备有多个通道时，地址、编号和区域只能在设备级统一维护。

区域卡片上的“管理”可重命名区域；只有区域为空时才能删除。

## 3. 查看实时画面

- 在“实时画面”中按区域、连接状态或关键词筛选摄像头；
- 点击单张卡片的“查看画面”进入单路预览；
- 单路预览使用 1280×720 / 8 FPS，四路画面墙使用 960×540 / 4 FPS，以控制多路解码占用；
- 单路画面断流后点击“重新连接”即可重新建立视频，不需关闭窗口；
- 四路画面墙中某一路断流时，可在对应画面格点击“重连”，其他画面不受影响；
- 点击工具栏“多路查看”，可同时查看当前筛选结果中的最多四路视频；
- 当前筛选结果超过四路时会先打开画面选择器，已选满四路后需先取消一路才能选择其他摄像头；
- 多路画面墙顶部会显示在线路数，关闭窗口会停止全部对应解码任务；
- 启动 60 秒后会自动检测一次，之后每 10 分钟检测一次；也可以点击“刷新设备状态”立即检测；
- 摄像头卡片会显示最近一次状态检测时间；
- 页面不会显示摄像头账号和密码。

## 4. 工作台

- 顶部显示摄像头在线数、高危险情、待处理险情；
- 指标卡显示设备在线率；
- 重点区域画面可快速进入实时视频；
- 待处理险情可直接进入处置；
- 值守摘要说明当前最需要关注的事项。

## 5. 处理险情

1. 进入“险情中心”；
2. 选择一条险情；
3. 查看等级、发生时间、区域、摄像头、来源和上报人；
4. 如果这条险情还没有区域，用“补充位置”选择正确的区域；补充后会记录在“处置记录”中；
5. 点击“确认处理”“标记已解决”或“标记误报”；
6. 已解决或误报的险情如需纠正，可点击“重新打开”并确认；
7. 险情详情的“处置记录”会显示创建、补充位置、确认、解决、误报和重新打开的操作人及时间；
8. 状态变化和重新打开都会写入本机审计记录。

## 6. 上报险情

方式一：点击右上角“上报险情”。

方式二：进入“现场问询”，输入：

```text
上报险情：成品仓库北门有人翻越围栏，目前仍在现场
```

平台会自动识别区域并创建险情。区域名可以只说一部分，例如配置为“成品仓库”时，说“仓库门口有人闯入”同样能匹配到。

如果两个区域名相近，平台不会随意猜测：险情会先创建但不带区域，随后在“险情中心”选中该条记录，用“补充位置”选择正确区域即可。

## 7. 现场问询

示例问题：

- 现在有哪些险情需要处理？
- 哪些摄像头离线了？
- 成品仓库现在是什么情况？
- 总结一下今天的现场情况。

未配置大模型时使用本地规则问答；配置后由大模型增强。回答只依据本地运营数据。该服务只处理文字摘要，不读取、不上传摄像头画面，也不执行视觉识别。

## 8. 系统设置

### 问询服务

可配置服务商、接口地址、模型 ID、API Key 和超时。取消“启用文字问询服务”后，配置会保留但运行时会回退本地规则。手工编辑 JSON 后如果地址不是 HTTP(S) 或超时无效，平台仍可启动，设置页会显示配置错误并使用本地规则。

### 险情通知

在“系统设置 → 险情通知”中可以启用 Webhook、邮件或短信。先打开总开关，再勾选渠道，对应字段才会启用：

- Webhook 地址必须使用 HTTPS，可填写 HMAC-SHA256 签名密钥；
- 邮件支持 STARTTLS、SSL/TLS 或不加密的 SMTP 服务；
- 短信支持企业自有 HTTPS JSON 网关，可配置签名、模板和接收号码；
- 已保存的 Webhook 密钥和邮件密码留空时保持不变；
- 点击“发送测试通知”验证配置；
- 手工编辑 JSON 后若渠道配置无效，设置页会显示“配置错误”和具体原因，不会静默假启用；
- 关闭通知总开关始终可以保存，即使某个渠道的配置尚未填写完整；
- 新险情会在后台发送，即使通知失败也不会影响险情保存；
- 险情详情会显示各渠道发送状态和尝试次数；
- 出现失败时可点击“重试险情通知”，只重试失败渠道；
- 系统也会对失败超过 60 秒且尝试未满 3 次的渠道自动退避重试；只重试失败渠道，不会重复发送已成功渠道。

### 国标服务

配置平台编号、SIP 域、端口和注册密码。保存后启动服务，设备注册成功后可导入。手工配置端口非法时平台仍可启动，设置页会显示“配置错误”；端口占用等服务启动失败原因会持续显示，不会被刷新覆盖。

服务状态按接入进度分级显示，便于判断链路是否真正可用：

| 状态 | 含义 | 下一步 |
| --- | --- | --- |
| 等待注册 | 服务已启动，但还没有任何设备连上来 | 在摄像头或 NVR 中填入平台编号与 SIP 域，填写正确的设备地址后发起注册 |
| 等待目录 | 设备已经注册，但还没有上报通道目录 | 确认设备已开启目录查询，或稍后刷新页面 |
| 待导入 | 设备已上报通道，还没有加入平台 | 点击“导入已注册设备”，选择区域后确认 |
| 已接入 | 通道已全部导入平台 | 可直接查看画面并接收设备告警 |

如果设备一直停留在“等待注册”，先核对设备侧的服务器地址、端口和 SIP 域是否与本页一致，以及本机防火墙是否放行该端口。

### 本地运行环境

显示配置文件、业务数据库和 FFmpeg 状态，可打开配置或数据目录。

- 点击“创建数据备份”会在数据库旁的 `backups/` 目录生成带时间戳的 ZIP；
- 备份包含 `factoryguard.db`、`factoryguard.json`、客户横幅 `branding/banner.svg`（如已配置）和 `manifest.json`；
- 数据库使用 SQLite 在线备份，不需要先退出程序；
- 备份包含明文配置凭据，请存放在受控位置；
- 本地运行环境会显示备份数量、总大小和最近备份时间；
- “打开备份目录”可直接查看已有备份；
- 点击“恢复备份”先校验 ZIP、清单和 SQLite 完整性，随后应用会退出；
- 摄像头在线状态与实时预览使用同一最佳码流，并在最近 30 分钟内完成检测后才显示在线；
- 下一次启动时、在打开业务数据库之前自动替换数据；
- 恢复前会在 `backups/` 自动创建安全备份；
- 恢复失败会回滚原数据，并在下一次启动时显示错误；
- 高于当前主版本的备份会被拒绝，防止数据库结构不兼容。

### 顶部品牌横幅

在“系统设置 → 顶部品牌横幅”上传客户自己的 SVG，调整显示高度并点击“保存并应用”。平台会自动复制文件并整条替换默认横幅。

- 建议使用 8:1 至 12:1 的横向 SVG，高度可设为 64～160 px；
- 文件最大 5 MB；不能包含脚本、事件属性、外部资源引用或 XML 实体声明；
- 上传前可在设置页预览；
- 点击“恢复默认横幅”可回到内置品牌外观。

## 9. 后台运行

同一 Windows 用户只允许运行一个 FactoryGuard 实例；重复启动会提示从现有窗口进入，避免重复建立摄像头服务。

关闭主窗口不会退出程序，窗口会隐藏到系统托盘并继续值守。

- 双击托盘图标：打开控制台；
- 托盘“上报险情”：打开窗口并上报；
- 托盘“刷新现场状态”：刷新设备与险情；
- 托盘“退出 FactoryGuard”：彻底退出。

## 10. 启动失败排查

- 配置文件格式错误时，平台会提示“配置文件错误”；
- 数据库损坏、目录无权限、磁盘空间不足或数据库被占用时，平台会提示“FactoryGuard 启动失败”；
- 按提示检查 `config/`、数据目录权限和磁盘空间，并确认没有其他程序占用数据库；
- 修复前先备份现有配置和数据库文件。

## 11. 安全提醒

- 当前配置文件中的 API Key 和密码为明文；
- 不要发送 `config/factoryguard.json`；
- 使用 Windows 账号和目录权限限制访问；
- 定期备份配置文件和业务数据库。
