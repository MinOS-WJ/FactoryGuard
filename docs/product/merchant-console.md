# 商户控制台产品说明

## 1. 产品定位

FactoryGuard 智守是面向商户店主、物业值班员和安保负责人的多摄像头、多区域管理平台。平台负责统一接入和展示视频信号，并把设备状态、用户上报和大语言模型文本问询收敛为可处置的“险情”。视觉侧不加载模型，也不执行画面分析。

## 2. 用户任务

| 用户目标 | 产品入口 | 结果 |
| --- | --- | --- |
| 快速知道现场是否安全 | 工作台 | 查看在线设备、区域、未关闭险情与值守摘要 |
| 查看某个摄像头 | 实时画面 | 按区域筛选并打开实时视频，断流后可重新连接 |
| 同时关注多个位置 | 实时画面 → 多路查看 | 从当前筛选结果中选择并同时查看最多四路视频，单格断流可独立重连 |
| 询问现场情况 | 现场问询 | 用自然语言获得有数据依据的回答 |
| 上报突发险情 | 右上角按钮 / 现场问询 | 创建险情并进入处置队列 |
| 处理一条险情 | 险情中心 | 确认、解决、标记误报，必要时重新打开 |
| 接入新摄像头 | 区域与设备 | ONVIF、GB/T 28181、RTSP 接入，并自动阻止重复连接 |
| 修改、暂停或撤掉摄像头 | 摄像头卡片“管理” | 编辑连接参数、暂停/恢复接入或删除设备 |
| 调整区域 | 区域卡片“管理” | 重命名空区域或删除区域 |

## 3. 信息架构

1. **工作台**：安全态势、指标、重点画面、待处理险情、值守摘要；
2. **实时画面**：区域/状态/关键词筛选，多摄像头卡片、最近检测时间、启动后首次及每 10 分钟自动状态检测、单路 8 FPS 播放和最多四路 4 FPS 同屏查看；
3. **现场问询**：聊天问询、建议问题、现场上下文、险情登记；
4. **险情中心**：筛选举报、查看详情、状态流转、处置记录和审计留痕，所有时间按本机时区显示；
5. **区域与设备**：区域卡片、摄像头卡片、ONVIF 扫描与接入向导；
6. **系统设置**：品牌横幅、险情通知、文字问询、GB/T 28181、本地运行环境、备份状态和备份/安全恢复。

摄像头暂停接入后不再取流，也不会生成设备险情；共享物理设备在其他通道仍启用时继续保留告警订阅。在线状态只采信最近 30 分钟内实际完成、且与实时预览一致的最佳码流检测；无时间戳或已过期的结果统一显示为“待检测”。

## 4. 险情状态机

```text
待处理 open
  ├── 确认处理 -> 处理中 acknowledged
  ├── 直接解决 -> 已解决 resolved
  └── 判断误报 -> 误报 false_alarm

处理中 acknowledged
  ├── 已解决 resolved
  └── 误报 false_alarm

已解决 resolved / 误报 false_alarm
  └── 确认后重新打开 -> 待处理 open
```

每次状态变化写入本地 `audit_log`，保留操作人与时间。

## 5. 文字问询边界

- 运营快照来自本地 SQLite 和实体拓扑；
- 快照包含区域、摄像头、设备状态、险情摘要和最近事件；
- 不包含设备密码、API 密钥、原始视频帧或完整数据库；
- 大模型回答必须遵循“只依据快照”的系统提示；
- 大模型不可用时自动降级为本地规则问答；工作台安全摘要和在线判定不依赖文字问询服务；
- 用户明确表达上报意图后，险情记录在本地创建，大模型只负责组织说明文字；
- 服务商、接口地址、模型、密钥和超时可在系统设置中维护。

## 6. 配置文件与业务数据

- 软件配置、模型参数、国标参数和设备凭据保存在 `config/factoryguard.json`；
- 可通过 `FACTORYGUARD_CONFIG` 或 `--config` 指定其他配置文件；
- 配置以明文 JSON 保存，适用于小规模本地部署，请限制文件访问权限；
- SQLite 仅保存区域、摄像头、险情、对话和审计等业务数据；
- 示例配置见 `config/factoryguard.example.json`。

## 7. 摄像头接入

### ONVIF

1. 局域网 WS-Discovery 扫描设备；
2. 用户填写 ONVIF 服务地址和设备账号；
3. 设备凭据写入本地 JSON 配置文件，不写入业务数据库；
4. 查看画面时由设备适配器解析实时码流。

### GB/T 28181

1. 系统设置中启用本机 SIP 服务；
2. 配置平台编号、SIP 域、端口和注册密码；
3. 摄像头注册并上报目录；
4. 将设备编号和通道绑定到区域。

### RTSP

1. 填写 RTSP 地址与所属区域；
2. 可先在接入向导中测试首帧；
3. 保存后直接进入实时画面。

## 8. 模型边界

- 软件不分发视觉模型文件，也不依赖 ONNX Runtime；
- 不提供目标检测、视觉模型绑定、置信度或输入尺寸配置；
- 可选大语言模型只处理文字化的设备、区域和险情摘要；
- 大语言模型不可用时仍可使用完整本地规则问答和险情管理。

## 9. 品牌横幅

- 顶部默认展示完整的深色品牌横幅；
- 商户可在系统设置上传自己的 SVG，保存后整条替换默认横幅；
- SVG 支持 64～160px 高度，按比例铺满并裁切，建议宽高比 8:1 至 12:1；
- 超过 5 MB、无法解析或包含脚本的 SVG 会被拒绝；
- 文件复制到 `branding/banner.svg`，配置中保存相对路径；
- 点击“恢复默认横幅”可回到内置品牌外观。

## 10. 可扩展方向

- 摄像头原生智能告警统一映射为 Incident；
- Webhook / 企业微信 / 短信通知直接发送险情摘要；
- 多租户与角色权限；
- 云端集中管理多个门店，本机端继续保留视频与隐私数据；
- 事件片段与录像索引在险情详情中回放。
