# 验收标准

## 1. 验收方式

验收分为自动测试、界面检查、配置检查和现场设备联调四类。自动测试通过不代表真实摄像头兼容性已完成，现场联调需单独签字确认。

| ID | 验收项 | 通过条件 | 验证方式 |
| --- | --- | --- | --- |
| AC-01 | 新控制台启动 | `python src/main.py` 显示启动画面并进入工作台 | 启动与界面检查 |
| AC-02 | 无视觉模型依赖 | 仓库、启动流程和 CLI 不包含视觉模型文件、ONNX Runtime 或画面推理命令；实时预览不得绘制检测框、置信度或目标标签叠层；不得提供像素规则评估、几何命中、轨迹模拟或视觉规则配置 | 代码检查、命令测试 |
| AC-03 | 多区域管理 | 可创建、重命名和删除场所，可创建区域和多台摄像头并保存；删除场所前必须先清空其区域；设备、区域、通道和码流引用必须保持一致；跨场所同名区域在险情、通知和问询中必须可区分；实时画面可按场所筛选 | 自动测试、界面检查 |
| AC-04 | 摄像头接入 | ONVIF、GB/T 28181、RTSP 向导字段随协议切换；ONVIF 扫描发现多台设备时可按名称和服务地址选择具体摄像头并预填向导；新增和编辑均不得与其他摄像头产生重复连接；ONVIF 与 RTSP 在保存前可测试连接并给出结果 | 自动测试、现场联调 |
| AC-04A | 摄像头维护 | 可编辑名称、区域和连接参数；账号或密码留空时分别保留旧值，不得互相覆盖；RTSP 特殊字符凭据可正确编码，IPv6 地址保持合法；可暂停/恢复接入；设备、通道和码流原子保存；共享设备删除非最后通道时不得中断其他通道告警；删除后历史险情保留 | 自动测试、界面检查 |
| AC-04B | 区域维护 | 同一场所内区域名称唯一，界面与存储层双重约束；新增和编辑均将场所与区域原子保存；父级区域必须存在且属于同一场所，禁止自引用；空区域可重命名或删除，非空区域阻止删除 | 自动测试 |
| AC-04C | 状态可信度 | 摄像头卡片与运营快照显示最近检测时间；无检测或超过 30 分钟的状态不得显示为在线；状态检测与预览使用同一最佳码流；设备地址或凭据变化后旧健康和缓存码流必须失效；仅保存凭据引用本身不得重置历史探测元数据 | 自动测试、界面检查 |
| AC-05 | 实时画面 | 可打开单路和最多四路同屏预览，超过四路时可自选画面，单路与画面墙使用分级预览参数，关闭画面墙停止全部解码，不崩溃且不显示凭据；取流失败须给出可操作的中文原因而非原始英文日志 | 自动测试、现场联调 |
| AC-06A | 险情清单导出 | 险情中心可将当前筛选结果导出为 CSV，包含发生时间、编号、等级、状态、来源、场所、区域、摄像头、上报人、描述和处置记录，中文在 Excel 中可直接打开 | 自动测试、界面检查 |
| AC-06 | 险情处置 | 可上报、确认、解决、误报，并可确认后重新打开；可填写现场处置说明并随状态变更留痕；已关闭险情必须先重新打开才能继续处理；非法状态转换不得写入审计；全部动作写入审计并以业务人员可理解的操作来源展示；全部未关闭险情不得被历史分页挤出；险情必须保留事发当时的区域与摄像头名称，区域改名或删除后仍可追溯 | 自动测试 |
| AC-06A | 告警响应 | 设备原生告警在约 1 秒内进入险情队列并触发提醒；不同设备复用事件号时不得互相去重；常见 ONVIF 技术主题须转换为业务可读标题；告警须绑定到对应区域和摄像头；平台不依赖预置画面规则才能接收设备告警；单条异常告警不得中断后续告警处理；设备瞬时断网后告警订阅必须自动恢复，无需人工干预 | 自动测试 |
| AC-07 | 现场问询 | 可查询设备、区域、险情，可自然语言登记险情；回答引用的 ID 必须可在险情中心追溯；5 分钟内重复提交同内容、同位置的未关闭险情不得重复建单或重复通知；登记险情必须保留区域归属 | 自动测试、界面检查 |
| AC-07A | 区域识别容错 | 上报险情时允许只说区域名的一部分或去掉方位词；两个区域同时匹配时不得随意归属，须保留为未指定并提示补充；险情创建后可在详情页补充区域与摄像头并留痕 | 自动测试、界面检查 |
| AC-08 | 本地规则回退 | 未配置大模型时核心问询仍可用 | 自动测试 |
| AC-09 | 大模型配置 | 服务商、地址、模型、密钥、超时和启停写入 JSON；手工配置错误不得阻断平台启动，应回退本地规则并显示脱敏错误，不得回显 API Key | 自动测试、文件检查 |
| AC-10 | 软件配置不写数据库 | LLM、GB28181、设备凭据不出现在 SQLite 配置表；摄像头拓扑保存失败不得遗留孤儿设备凭据 | 代码检查、迁移测试 |
| AC-11 | 配置文件可迁移 | 旧注册表/数据库配置可一次迁移；已有模型、服务商和国标设置不得被旧空值覆盖；旧凭据仅在成功写入 JSON 后删除，无法解密的凭据保留 | 迁移测试、现场检查 |
| AC-12 | 配置文件错误处理 | 非法 JSON 给出明确错误且不覆盖原文件；局部更新嵌套配置时不得丢失同级字段 | 自动测试 |
| AC-12A | 启动故障处理 | 数据库损坏、目录无权限或文件占用时显示可操作错误，不暴露 Python 堆栈；配置文件损坏时提示必须包含配置文件路径、可用备份和恢复步骤；可选国标/文字服务配置错误不得阻断平台启动；随机端口绑定失败不得泄漏 socket 或事件循环 | 自动测试、手动检查 |
| AC-13 | 后台常驻 | 关闭窗口后隐藏到托盘，后台计时器和服务继续运行；可设置开机后自动在后台值守，且不修改注册表、不需要管理员权限；任一后台任务异常不得中断其他任务或终止进程 | 自动测试、Windows 手动检查 |
| AC-13A | 单实例运行 | 重复启动被阻止并提示从现有窗口进入，不重复建立摄像头服务；设备订阅和服务停止后快速重启不得被旧线程状态干扰 | 自动测试、Windows 手动检查 |
| AC-14 | 显式退出 | 托盘退出后释放线程、停止国标服务并关闭数据存储；窗口已隐藏时退出同样必须释放全部资源；停止中的线程不得误删重启后的服务状态 | 自动测试、手动检查 |
| AC-15 | 启动画面 | 显示品牌、版本、当前阶段和进度百分比 | UI 自动测试、截图检查 |
| AC-16 | 响应式布局 | 1120×640、1280×720、1366×768、1440×900 无水平溢出，兼容常见高 DPI 逻辑分辨率 | 截图检查、自动测试 |
| AC-17 | 全量回归 | `python -m pytest -q` 全部通过 | 测试报告 |
| AC-17A | 本地数据备份 | 可在线生成包含配置、数据库快照、客户 SVG 横幅和清单的 ZIP；配置缺失时仍应保留存在的客户 SVG；备份数据库可独立打开 | 自动测试、手动检查 |
| AC-17B | 安全恢复备份 | 恢复前校验包、数据库和清单成员一致性；下次启动前替换数据；失败回滚并保留恢复前备份 | 自动测试、手动检查 |
| AC-18 | 简洁视觉 | 单一强调色、中性卡片、无重阴影和大面积多色渐变 | 截图检查 |
| AC-19 | 无预置客户参数 | 未配置时不预填服务商、接口、模型、平台编号和 SIP 域 | 自动测试、配置检查 |
| AC-20 | SVG 顶部横幅 | 默认可显示完整品牌横幅；客户 SVG 可预览、保存并整条替换；未确认预览不得覆盖当前横幅；脚本、事件属性、外部资源和实体声明被拒绝；恢复默认后仍显示默认横幅 | 自动测试、截图检查 |
| AC-21 | 多摄像头模拟工具 | 可启动多路虚拟摄像头，并通过 ONVIF、GB/T 28181 和 RTSP 完成发现、注册和取流 | 模拟器自动测试 |
| AC-23 | 险情通知 | Webhook/邮件/短信可配置、可测试；结果持久化，失败渠道可单独重试且不阻断业务；线程异常兜底不得重试已成功渠道；已停用渠道不得进入手动或自动重试；失败渠道不得因达到固定次数而永久放弃，应按退避策略持续补发；通知关闭后仍可查看历史投递和失败原因；手工 JSON 配置无效时必须显示错误而非静默禁用；总开关关闭时必须能够立即保存停用状态并保留渠道草稿；投递详情使用业务渠道名称 | 自动测试、界面检查 |
| AC-25 | 长期运行稳定 | 后台常驻期间数据库体积可控：过期设备事件、审计日志和已投递通知自动清理，WAL 定期压缩；不再被引用的设备凭据自动清理；险情与通知历史不得被自动删除 | 自动测试 |
| AC-22 | 源码质量门禁 | `ruff check`、`ruff format --check` 和 `compileall` 全部通过 | 自动测试 |
| AC-24 | 国标通道导入 | 从国标服务导入的设备与通道一次事务写入，任一通道失败整体回滚且不留下半套数据；导入区域在跨场所重名时可区分；导入后该通道的设备告警必须归属到所选区域和摄像头；同一国标设备编号不得重复导入到不同区域 | 自动测试、现场联调 |
| AC-24A | 国标服务状态可信 | 启用国标服务后，界面按“等待注册 / 等待目录 / 待导入 / 已接入”分级显示状态，不得在尚无设备接入时显示为已完全可用；每种状态都要给出下一步可执行的操作提示 | 自动测试、界面检查 |

## 2. 阻断验收问题

以下任一问题存在时不具备交付条件：

- 启动崩溃或配置损坏导致无法进入程序；
- 关闭窗口后线程或应用崩溃；
- 配置仍写入 SQLite 或 Windows 注册表；
- 摄像头密码显示在界面；
- 险情记录或审计无法保存；
- 窗口无法重新打开或无法彻底退出；
- 自动测试或 Ruff 质量门禁失败；
- 客户 SVG 无法保存或恢复默认横幅后出现空白顶部区域。

## 3. 现场联调清单

- ONVIF 发现、认证、通道枚举与实时码流；
- GB/T 28181 注册、目录、告警和实时点播；
- RTSP 主/子码流实际地址；
- 断电、断网、恢复后的状态刷新；
- Windows 托盘图标、通知和开机启动策略。
